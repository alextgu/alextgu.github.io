# Computer view assets

Assets for content that opens in the computer (folder windows).

- **hackathons/** — Images for Hackathons folder entries. Reference in `content.json` as `/assets/computer/hackathons/your-file.png`.
- **website/** — Images for Website timeline (e.g. screenshots). Reference as `/assets/computer/website/...`.
- **alex/** — Images for the alex folder. Move `majors.JPG` here and reference as `/assets/computer/alex/majors.JPG`.

Add more subfolders here for future computer pages (e.g. `experiences`, `projects`).
